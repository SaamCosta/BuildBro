## Level of detail: detailed

The player wants something they would be glad to show a friend.

- Give the walls depth: a base course in a darker block, corner pillars or logs, windows set one block into the wall, a roof that overhangs by one block.
- Use three or four materials that belong together, and mix similar blocks (for example stone bricks with some cracked and mossy ones) so walls do not look flat.
- Make the roof with the `roof` tool, then add trim if you like (upside-down stairs under the eaves, a chimney).
- Frame doors and windows; add lanterns or torches outside, away from the door approaches.
- If the building can be entered, furnish each room for its purpose, following the interior rules.
- Finish the base where it meets the ground: a path to each door, a few plants.
